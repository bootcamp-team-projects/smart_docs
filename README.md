# Smart Project Docs — 팀 프로젝트 문서

Smart 팀 프로젝트의 기획, 설계, API, 데이터 구조 및 협업 산출물을 정리하는 문서 저장소입니다.

## 목적

앱·웹 서비스와 데이터/AI 모듈 간의 공통 이해를 돕고, 개발 과정에서 합의한 요구사항과 설계 내용을 관리합니다.

## 문서 정리 권장 항목

- 프로젝트 개요 및 사용자 요구사항
- 시스템 아키텍처와 주요 모듈 관계
- API 명세 및 요청·응답 예시
- 데이터베이스 스키마 및 ERD
- 설치·실행 환경과 배포 절차
- 팀 역할, 결정 사항 및 변경 이력

위 항목은 문서 디렉터리에 실제 존재하는 자료에 맞춰 유지하고, 아직 작성되지 않은 문서는 완료된 것으로 표현하지 않습니다.

## 관련 저장소

- [Smart Web](https://github.com/bootcamp-team-projects/smart_web) — 웹 프론트엔드 및 서비스 연동
- [Smart App](https://github.com/bootcamp-team-projects/smart_app) — 앱 및 API 구성
- [Smart ML](https://github.com/bootcamp-team-projects/smart_ml) — 머신러닝 관련 작업
- [Smart DL](https://github.com/bootcamp-team-projects/smart_dl) — 딥러닝 관련 작업

## 기여 및 유지관리

문서는 코드 변경과 함께 업데이트하고, 실제 구현과 일치하지 않는 설계·실행 안내는 수정하세요. 비밀키, 비공개 사용자 정보, 실제 인증 정보는 문서에 포함하지 않습니다.
